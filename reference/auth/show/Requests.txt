- requests  definition  accepted
  A user has access to a path when some request for it is admitted on their behalf.
  why: A user reaches a resource only through requests, and a request carries a token, not a user: the system sees tokens.

Formally (as written in Scala)
    access := (u: Term[UserId], p: Term[Path]) => exists((t: Term[String]) => admit(t, p) === Some(u))

Where it sits
  used by    + accessExactly: "A user gets access to a resource exactly when they are signed in and authorized for it."

Vocabulary
  access: whether the system lets the user access the resource (defined by requests)
  admit (operation): the system's decision on a request (a token and a path): the user it is admitted on behalf of, if any (open)
