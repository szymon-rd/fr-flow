- grantTable  definition  accepted
  A user is authorized for a path when a grant names that user and that path.
  why: The idea defines authorization as a table of grants; who may change the table is not modelled.

Formally (as written in Scala)
    authorized := (u: Term[UserId], p: Term[Path]) => grants.contains(Grant(u, p))

Where it sits

Vocabulary

  grants: the grant table as stored when the request is decided (open)
