- clockKept  assumption  accepted
  The clock gives the time now, in seconds; a sleep moves it on by the time asked and by a delay it may add, never less, and nothing else moves it while a flow runs.
  why: Q9: the server's clock, in seconds, read once per request and once per run of housekeeping. Steps take no time (the synchronous hypothesis), so a request answers at one moment. The fake clock, used in tests, is tested against this model; the computer's clock (SystemClock) is assumed to keep it.

Formally (as written in Scala)
  model:
    now = do
        let c ← get
        pure c.now
    sleep = fun (seconds : Int) => do
        modify (fun c => (ClockState.mk ((c.now + (max seconds 0)) + (max (Option.getD (List.head? c.delays) 0) 0)) (List.drop (Int.toNat 1) c.delays)))
