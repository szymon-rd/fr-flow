## Domain used here

- **Request**: A request presenting `token` asks to perform `action` on `resource`.
- **Token**: A bearer credential issued at login.
- **ResourceId**: Anything access to which is controlled.
- **Action**: An operation a principal can perform on a resource.
- **ServiceState**: State of the authorization service.
- **RbacPolicy**: A role-based access-control policy.
- **UserId**: A principal: a person or a service that acts on the system.
- **Role**: A named set of permissions held by principals.
- **Permission**: Permission for holders of `role` to perform `action` on `resource`.
- **Access**: A recorded access: `user` performed `action` on `resource`, decided under policy version `version`.
- **SetPolicy**: A new policy version comes into force.
- **PublishPolicy**: An administrator publishes a new RBAC policy version.
- **Logout**: `token` is revoked.
- **SessionState**: Design state: sessions bind tokens to principals.
- **Login**: An authenticated principal receives `token`.
- `ServiceState.allows`: Whether a request is allowed: its token has a session whose principal the current policy permits.
- `ServiceState.permittedAt`: Whether policy version `v` permits `user` to perform `action` on `resource`.
- `RbacPolicy.permits`: Whether `user` holds a role that is permitted `action` on `resource`.
- `ServiceState.principal`: The principal a token is bound to, or `UserId.Anonymous` for an unknown token.
- `UserId.Anonymous`: The principal of a request whose token is not bound to anyone.

```scala
final case class Request(token: Token, resource: ResourceId, action: Action)

final case class Token(value: String)

final case class ResourceId(path: String)

enum Action:
  case Read, Write, Delete

final case class ServiceState(version: Int, policies: Map[Int, RbacPolicy], sessions: Map[Token, UserId], log: List[Access]):

  /** The principal a token is bound to, or `UserId.Anonymous` for an unknown token. */
  def principal(token: Token): UserId = sessions.getOrElse(token, UserId.Anonymous)

  /** Whether policy version `v` permits `user` to perform `action` on `resource`. */
  def permittedAt(v: Int, user: UserId, resource: ResourceId, action: Action): Boolean =
    policies.get(v).exists(_.permits(user, resource, action))

  /** Whether a request is allowed: its token has a session whose principal the current policy permits. */
  def allows(r: Request): Boolean =
    sessions.get(r.token).exists(u => permittedAt(version, u, r.resource, r.action))

final case class RbacPolicy(roles: Map[UserId, Set[Role]], permissions: Set[Permission]):

  /** Whether `user` holds a role that is permitted `action` on `resource`. */
  def permits(user: UserId, resource: ResourceId, action: Action): Boolean =
    roles.get(user).exists(held => held.exists(role => permissions.contains(Permission(role, resource, action))))

  /** This policy with every role of `user` revoked. */
  def revokeAll(user: UserId): RbacPolicy = copy(roles = roles.removed(user))

final case class UserId(name: String)

final case class Role(name: String)

final case class Permission(role: Role, resource: ResourceId, action: Action)

final case class Access(user: UserId, resource: ResourceId, action: Action, version: Int)

final case class SetPolicy(policy: Policy)

final case class PublishPolicy(policy: RbacPolicy)

final case class Logout(token: Token)

final case class SessionState(version: Int, policy: Int => Policy, sessions: Map[Token, UserId], log: List[Access]):

  /** The principal a token is bound to, or `UserId.Anonymous` for an unknown token. */
  def principal(token: Token): UserId = sessions.getOrElse(token, UserId.Anonymous)

final case class Login(user: UserId, token: Token)

// UserId.Anonymous
val Anonymous: UserId = UserId("")
```

## Path from the root

### R0 NoUnauthorizedAccess, requirements

**Statement.** Every recorded access was permitted by the policy in force when it was decided.

**Rationale.** States the security goal without any mechanism. Policies change over time, so the goal is relative to the policy version in force at decision time; published versions never change.

**Requirement `Safe`.** Every logged access was permitted by the policy version it was decided under, and that version is not in the future.

```scala
{
    s => s.log.forall(e => e.version <= s.version && s.policy(e.version)(e.user, e.resource, e.action))
  }
```

### D1 AuthnThenAuthz, design

**Statement.** Access is granted only to the principal bound to the presented token, under the current policy.

**Rationale.** Separates identity (sessions created at login) from permission (the policy decision). The system observes only the presented token, so linking it to the real requester relies on A1 and A2.

**Invariant `SessionsNamed`.** Every session is bound to a named principal, never to Anonymous.

```scala
{
    s => s.sessions.forall((_, u) => u != UserId.Anonymous)
  }
```

### I2 RbacService, implementation (this layer)

**Statement.** Policies are role-based and versioned, and every decision uses the current version.

**Rationale.** RBAC keeps policies small and reviewable. Published versions are retained, so every audit entry can be checked against the policy it was decided under.

## Assumptions in scope

- **A1 TokenHolderIsPrincipal.** A request presenting a token bound to principal u is issued by u. Justification: Tokens are random, unguessable, sent only over TLS, and never shared or logged.
- **A2 LoginAfterAuthentication.** A token is bound to principal u only after u has been authenticated. Justification: Only the authentication service calls login, after verifying the principal's credentials.
